# 실제 기사 라벨링 홀드아웃

이 디렉터리는 AgendaFrame의 출시 평가에 사용할 실제 기사 라벨링 패킷을 관리합니다.

- `manifest.jsonl`은 연구자가 제공한 2026-07-26 기사 표본에서 만든 **라벨링 대기 패킷**입니다.
- 기사 본문·HTML·사진은 커밋하지 않습니다. 각 레코드는 원문 URL, 기사 식별자, 게시 시각과 비복원 본문 SHA-256만 가집니다.
- `case_id`는 같은 사건일 수 있는 후보를 묶은 값일 뿐, 정답이 아닙니다. 두 명의 독립 코더가 원문을 확인해 사건 동일성부터 판정해야 합니다.
- 각 사례는 서로 다른 코더 2명의 라벨과 제3자(또는 합의 절차)의 adjudication, 일치도 보고서, 잠금된 holdout 분할을 모두 요구합니다.
- `license_basis`가 `pending_confirmation`인 동안은 연구용 내부 라벨링 준비 상태이며 출시 증거로 사용할 수 없습니다. 퍼블리셔·데이터 제공자의 이용 허락 또는 적법한 연구 근거를 `license_basis`에 기록한 후에만 평가 입력으로 승격합니다.

## 라벨링 순서

1. 코더 A와 B가 원문을 독립적으로 확인합니다.
2. 사건 단위, 문제 정의, 원인, 책임, 평가, 해법, 행위자 가시성을 코드북에 따라 라벨링합니다.
3. 각 라벨은 문단·문장 위치와 비복원 해시를 기록합니다. 원문 문장을 패킷이나 저장소에 복사하지 않습니다.
4. 불일치는 adjudicator가 해결하고, 변경 이유와 코드북 버전을 기록합니다.
5. 라벨·일치도·adjudication이 완료된 잠금 holdout만 `release_eligible` 평가에 사용합니다.

실제 사람이 입력한 라벨이 없는 상태에서 이 패킷을 gold 데이터나 통과 증거로 표현하지 않습니다.
