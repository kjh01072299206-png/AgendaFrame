# AgendaFrame 스프린트 백로그

원본 작성: 2026-07-07 · 현행화: 2026-08-03

스프린트 1~4는 종료됐다. 계획 대비 결과와 변경 사항만 요약하고, 상세 작업 표는
완료 기록으로 유지한다. 잔여 핵심 작업은 스프린트 5·6으로 재편성했다.

## 완료 스프린트 요약 (스프린트 1~4)

| 스프린트 | 목표 | 결과 | 계획 대비 변경 |
| --- | --- | --- | --- |
| 1. 기사 수집 MVP | 3개 언론사 메타데이터 수집 | **완료** — 22개 매체, 누적 39,023건, 수집 시각·freshness 표시 | Playwright 상시 크롤링 → BigKinds Excel/CSV 가져오기 + 홈페이지 배치 관측 API로 피벗 |
| 2. 저장·이슈 묶기 | 저장 스키마·클러스터링·초기 검증 | **대부분 완료** — D1 스키마, 전문 비저장 계약, 일일 클러스터링(18개 분석일), 검증 UI·정밀도/재현율 산출 로직 | 실측 라벨 비교(PBL-07)는 미완 → 스프린트 5로 이관 |
| 3. 의제 점수·대시보드 | 랭킹·이슈 상세·언론사 비교 | **완료** — 가중 의제 점수(다양성 45·기사량 30·배치 15·후속 10), 랭킹·상세·보도량/배치 비교, 6분류 필터, 제목 비교 | 기사 정렬 토글·제목 키워드 강조는 잔여 소작업 |
| 4. 프레임·AI 리포트 | 프레임 분석·리포트·MVP 검증 | **대부분 완료** — 문제정의·원인·책임·평가·해법+취재원 구조 분석, 프레임 비중 그래프·근거 패널, 규칙 기반 리포트, Gemini 시맨틱 파일럿(initial five 25건) | 프레임 코드북을 6종 → Entman 계열 구조로 교체. 수동 검증 실측(PBL-14)은 미완 → 스프린트 5로 이관. LLM 리포트는 오프라인 경로 한정 |

계획에 없었으나 이 기간에 추가 구현된 것: initial-five 공개 계약, 근거 챗봇 2종,
커뮤니티 허브, 읽기 자기점검·방법론 페이지, 관리자 품질 검증, 한국어 형태소
fallback, 릴리스 게이트·카나리·롤백 결정 로직, 발행 outbox·내구 작업 큐.
(프로덕트 백로그 PBL-21~28 참조)
