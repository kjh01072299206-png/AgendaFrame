상태 값: `완료` = 코드·테스트로 확인됨, `완료(미배포)` = 저장소에는 있으나 공개 URL에 아직 반영 안 됨, `부분 완료` = 핵심 동작은 있으나 완료 조건 일부 미충족, `대기` = 미착수.
