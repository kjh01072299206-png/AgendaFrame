# AgendaFrame 최종 의미·출시 검토 체크리스트

이 문서는 기능 완료 여부가 아니라, 공개 화면의 의미가 근거 범위를 넘지 않는지 확인하는 마지막 검토표입니다.

## 의미 검토

- [ ] 모든 이슈가 같은 사건과 후속 사건을 구분해 묶였는가
- [ ] 기사량·홈 배치·집중도가 중요도, 진실성, 여론 점수처럼 보이지 않는가
- [ ] `explicit_not_stated`/`not_observed`가 빈칸이나 사실 부재로 오해되지 않는가
- [ ] 제목 기반 결과와 본문 기반 결과가 화면에서 구분되는가
- [ ] 각 비교 주장에 기사 ID·원문 URL·근거 위치/해시가 연결되는가
- [ ] 취재원 구성은 등장 여부만 관측하고, 신뢰도나 편향을 추정하지 않는가
- [ ] 보도되지 않은 사실을 의도적 누락으로 단정하지 않는가
- [ ] 자기점검과 챗봇이 사용자의 판단을 대신한다고 표현하지 않는가
- [ ] 신고·댓글에 개인정보, 혐오, 명예훼손을 유도하는 문구가 없는가

## 출시 통과 조건

- [ ] `evals/thresholds.yaml`의 모든 지표 기준을 실측했다.
- [ ] 실제 기사, 독립 코더 2명, adjudication, 일치도 보고서, 잠금 holdout, 이용 근거가 확인됐다.
- [ ] `python scripts/release_gate.py`가 `release_eligible: true`를 반환한다.
- [ ] 스테이징에서 health/SLO·로그·신고 큐를 확인했다.
- [ ] 카나리 관찰 구간 동안 오류율·지연·근거 없는 답변이 예산 안이다.
- [ ] 실패 시 이전 immutable 버전으로 되돌릴 수 있고 복구 리허설을 기록했다.
- [ ] 공개 URL에서 새 버전과 이전 버전의 주요 이슈·근거·댓글 상태를 확인했다.

실제 사람 라벨과 이용 근거가 입력되기 전에는 이 체크리스트의 출시 통과를 선언하지 않습니다.
