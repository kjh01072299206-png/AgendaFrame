# 프로토타입 UI 이식 기록 (2026-10-07)

## 확인한 원인

- 작업 시작 시 이 워크트리는 detached HEAD `dc831d9`였으나, 공개 `/version`과
  GitHub main은 모두 `ea427b4d4467ac8c1bd8d7c30043d3b74d03b24a`였다.
  변경 전 `git status --short`는 비어 있었다. 최신 main에서 작업 브랜치를 만들었다.
- `/`는 `site/app/(shell)/page.tsx` → `ActiveSnapshotHome`으로 렌더링된다.
  기존 `active-home.tsx`는 순위 막대 목록과 별도 미리보기를 출력했다.
  기준 `tmp/claude-framing-2026-07-26/prototype/app.html`의 `vHome`는
  분야 분포 → 의제 카드 → 갈림 한 장면을 출력한다. CSS만 변경해서는 이 차이가 없어지지 않는다.
- 프로토타입은 Pretendard Variable 1.3.9를 로드한다. 기존 앱에는 이를 로드하는
  `@font-face`나 링크가 없었다. 동일 배포본의 글꼴과 OFL 라이선스를 앱에 포함했다.
- `app-shell.css`는 모바일 `.afs-nav-sec`를 `display: contents`로 바꾸지만,
  `app-round2.css`의 마지막 모바일 규칙은 다시 `display: block`으로 만든다.
  실제 390px 화면에서 내비 그룹이 세로로 쌓였다. 셸 안의 이식 스타일에 충분한
  선택자 우선순위를 부여해 뒤의 기존 스타일이 이를 덮어쓰지 못하게 했다.
- 비교·프레이밍 경로는 `IssueSubject` 제목·탭을 출력한 뒤 자체 페이지 제목을
  다시 출력했다. 프로토타입에는 이 중복 영역이 없다. 분석 경로에서 중복을 제거하고
  선택한 의제·순위는 상단 선택기와 페이지 설명에 유지했다.

## 변경 범위

- 홈 구역 순서, 카드 그리드, 분야 막대, 갈림 요약을 실제 active snapshot으로 렌더링한다.
- 셸 236px 내비, 22px 본문 여백, 24px 페이지 제목, 12px 카드 모서리,
  선택된 내비의 파란 배경, 로고·상단 아이콘·분석 범위 패널을 기준 소스에 맞춘다.
- 기존 추가 기능은 접을 수 있는 내비에 유지한다. 찜하기·프레이밍 링크·보고서 링크도 유지한다.
- 비교 패널의 큰 제목·과도한 여백·그림자를 줄이고 근거 펼침을 유지한다.
  기사별 긴 설명·상세 프레임 관측은 추가 분석 펼침 안에 유지하며,
  취재원 발언의 보조 관측도 기본 접힘 상태로 표시한다.
- 홈 렌더 관문은 구역 순서, 카드 5개와 실제 비교 경로, 글꼴 로딩,
  데스크톱 내비 너비를 검사한다. 모바일 상호작용 검사는 현재 화면의 내비를 검사한다.

## 데이터와 검증의 경계

- 7월 26일의 기사·수치·논조 그룹을 현재 공개 데이터로 섞지 않았다.
  분야 막대는 현재 공개 표본의 집계이며 하루 전체 수집분으로 표시하지 않는다.
  기간 집계가 없는 주간·월간 버튼은 비활성 상태다.
- 현재 표본에 근거 연결된 차이가 없으면 갈림 카드를 만들어내지 않고 보류 상태를 유지한다.
- 원본 HTML·CSS는 읽었으나 인앱 브라우저가 `file://` 열기를 차단해
  원본 화면 직접 캡처·픽셀 차이 측정은 하지 못했다. 원본과 완전한 픽셀 동일성을
  검증했다고 주장하지 않는다. 공개 전후 및 로컬 각 폭의 캡처는 `tmp/`에 둔다.
- Vercel Root Directory는 `site`, 프레임워크는 Next.js이며 `site/vercel.json`의
  `next build`가 실제 배포 빌드다. package.json의 일반 `build`/`start`는 Vite이므로
  공개 화면 검증은 `next build`와 `next start`로 수행한다.
