# 12개 매체 기사 수집 활성화 인계서

## 확정 범위

- 운영 수집 기간: 2026-08-13부터 2026-10-31까지(Asia/Seoul)
- 2026-08-10 검증 기록은 운영 시작 전 endpoint·parser 점검으로 보존한다.
- 매체: 경향신문, 국민일보, 동아일보, 문화일보, 서울신문, 세계일보, 조선일보, 중앙일보, 한겨레, 한국일보, KBS, SBS
- 분야: 정치, 경제, 사회, 국제
- 매체 가중치: 신문사와 방송사 모두 매체당 1
- 제외: 사설·칼럼·기고·오피니언, 유료·로그인 제한, 사진·영상 전용, 광고·댓글
- 원문: 비공개 R2에만 저장하며 공개 근거 사용은 금지한다. 2026-10-31 23:59:59 KST 이후 R2 객체를 삭제하고 D1에는 해시·글자 수·만료 상태 등 메타데이터만 남긴다.

## 현재 구현 상태

예약 실행 경로는 `발견 문서 요청 → 최근 3개 KST 날짜 범위 확인 → URL/분야 필터 → D1 메타데이터 저장 → 기사 본문 요청·추출 → 비공개 R2 저장 → 기사별 프레임 프로필 → 해당 날짜 이슈 분석·게시 대기열 → 만료 원문 삭제 → 기존 운영 유지보수` 순서다.

2026-08-10 실접속 검증에서 경향신문·국민일보·동아일보·문화일보·서울신문·세계일보·조선일보·중앙일보·한겨레·한국일보·KBS·SBS의 목록과 대표 본문 추출이 통과했다. KBS의 `/api`는 robots에서 금지하므로 사용하지 않고, robots가 공개한 `recentNewsList.xml` 사이트맵에서 URL을 발견한 뒤 기사 페이지의 분야 표식을 확인해 네 분야만 남긴다. 국민일보 robots 요청은 일시 네트워크 오류가 두 번 발생했으나 후속 단독 검증에서 네 분야와 본문이 모두 통과했다.

MBC는 일반 user-agent에 `Disallow: /`를 선언하므로 수집 범위에서 제외했다. 우회나 다른 봇 사칭은 하지 않는다. 나머지 12개 매체는 `verified`, 모든 검증 엔드포인트는 `enabled: true`, 전체 상태는 `active`다. 이 설정은 배포 후 예약 실행 또는 인증된 운영 호출이 있어야 언론사 요청을 시작한다. 403 또는 429가 나오면 해당 매체는 같은 실행 안에서 즉시 중단된다. 요청은 한 번에 하나만 보내고 요청 사이 간격은 최소 3초다.

한 요청은 15초에 중단되고 응답 본문은 스트리밍 중 2MB를 넘으면 폐기한다. 한 회차는 12분 이후 새 언론사 요청이나 분석 단계를 시작하지 않는다. 크론과 관리자 수동 실행은 D1의 60분 전역 임대 잠금을 공유하므로 동시에 실행되지 않는다. 본문 수집 실패는 기사별로 D1에 기록하며 15분부터 지수 백오프하고 5회 실패하면 자동 재시도를 끝낸다.

## 실제 수집 전 반드시 끝낼 일

1. 비운영 환경에 D1·비공개 R2·운영 토큰을 연결하고 마이그레이션을 적용한다.
   특히 `0011_collection_execution_lock.sql`, `0012_article_collection_attempts.sql`까지 적용되지 않으면 예약 실행을 켜지 않는다.
2. 비운영 D1·R2에서 1회 수동 실행해 발견 수, 분야 오분류, 중복률, 본문 추출 실패, 403/429를 확인한다. 특히 KBS 사이트맵에서 발견된 `pending` 기사가 기사 페이지 기준으로 네 분야 또는 `excluded`로 갱신되는지 확인한다.
3. 자동 실행 시각은 매일 00:00·06:00·12:00·18:00 KST다. 배포 산출물에는 이에 대응하는 UTC cron `0 3,9,15,21 * * *`를 포함한다. 상태는 `GET /api/admin/collection/status`에서 확인한다. 예약 실행과 R2 삭제가 실제로 호출되는 것을 확인하기 전에는 수집이 가동된 것으로 보지 않는다.
4. 비운영 결과를 승인한 뒤 동일한 바인딩과 예약 실행을 운영 환경에 적용하고 첫 실행을 감시한다.
5. 10월 31일 이후에도 삭제 작업이 끝날 때까지 Worker와 예약 실행을 유지한다. R2 삭제 수와 D1의 `article_contents.status='expired'` 수를 대조하고, 실패 목록이 0인지 확인한 뒤 서비스와 백업을 종료한다.
   삭제는 회차당 최대 500건씩 최대 20배치를 비우지만, R2 삭제 실패가 있으면 `drained=false`이므로 운영자가 재실행·확인해야 한다.

## 구현상 특히 어려운 부분

- 매체별 목록 구조와 기사 URL은 수시로 바뀌며 일부는 JavaScript 렌더링이라 정적 HTML 발견이 실패할 수 있다.
- 방송 뉴스 페이지는 영상 중심·텍스트 기사·다시보기가 섞여 있어 텍스트 기사만 판별하는 매체별 규칙이 필요하다.
- 홈페이지에서 분야를 확정할 수 없는 링크는 안전하게 버린다. KBS만 공식 사이트맵 특성상 `pending`으로 발견한 뒤 기사 페이지의 `category-name` 표식으로 분야를 확정한다.
- MBC는 이번 12개 패널에 포함하지 않는다. 향후 허용된 RSS/API·제휴 피드가 생길 때만 별도 범위 변경으로 재검토한다.
- R2 삭제 코드는 애플리케이션이 관리하는 원문 객체를 지우지만 플랫폼 백업·로그·외부 모델 제공자 보존분까지 자동으로 증명하지 못한다. 해당 서비스별 보존 설정과 삭제 확인 기록이 별도로 필요하다.
- 본문 수집 실패는 새 기사 영구 정체를 막도록 백오프하지만, 매체 단위 `Retry-After`를 실행 간 공유하는 영속 쿨다운과 분석 실패의 별도 백오프는 아직 운영 보강 항목이다.
- 현재 전체 사이트 린트는 기존 수정 중인 `site/app/agenda-dashboard.tsx`의 React memoization 오류 때문에 실패한다. 새 수집 파일만 대상으로 한 린트와 전체 빌드·테스트는 통과했다.

## 2026-08-10 검증 기록

- 실접속: 확정된 12개 매체의 robots, 모든 설정 목록 엔드포인트, 매체별 대표 본문 추출을 확인했다. 국민일보는 일시 네트워크 오류 후 단독 재검증에서 통과했다.
- 오프라인: 프로덕션 Vite 빌드와 158개 테스트, TypeScript 검사, 변경 파일 ESLint가 통과했다. 일 4회 스케줄, 요청 타임아웃·용량 제한·실행 마감, 전역 임대 잠금, 단계·리다이렉트 간 공통 요청 간격, 기사별 재시도, 종료 후 원문 삭제 드레인 회귀 테스트를 포함한다.
- 남은 저장소 게이트: 전체 ESLint는 기존 `agenda-dashboard.tsx` 오류 1건 때문에 실패했다. 로컬 브라우저 감사는 기존 외부 폰트·파비콘 CSP 오류와 일부 500 응답을 포함해 215건을 보고했으므로 사이트 변경분과 분리해 해결해야 한다.
- 배포·예약 실행: 기존 공개 프로덕션에는 배포하지 않았다. 대신 소유자 1명만 접근할 수 있는 별도 Sites 프로젝트 `AgendaFrame Collection Staging`(버전 1)에 D1·R2·`IMPORT_TOKEN`을 연결해 배포했다. 스테이징 URL은 `https://agendaframe-collection-staging.kjh01072299206.chatgpt.site`이다.
- 스테이징 상태 확인: `GET /api/admin/collection/status`에서 수집 기간, 12개 매체, 일 4회 스케줄이 모두 활성 상태이고 최초 실행 전 기사 수가 0건임을 확인했다.
- 스테이징 1회 실행: 실제 수동 실행에서 12개 매체, 기사 메타데이터 2,186건, 비공개 본문 4건, 본문 구조화 프로필 4건을 저장했다. 별도 하루 분석은 기사 2,186건, 본문 근거 4건, 이슈 80개로 완료됐다.
- 남은 라이브 결함: 수동 수집 요청은 내부 저장을 성공시킨 뒤 HTTP 400 `INVALID_REQUEST`를 반환했다. 마지막 집계·유지보수 단계 또는 응답 조립 경로를 보강한 새 버전을 다시 배포하고, 같은 스테이징에서 성공 응답과 다음 cron 로그를 확인하기 전에는 프로덕션 활성화로 간주하지 않는다.
- 날짜 경계: 발견 단계뿐 아니라 D1 저장 직전에도 KST `2026-08-10`~`2026-10-31` 밖의 명시적 발행 시각을 거부한다. 다만 HTML 목록의 날짜 없는 링크는 발견일을 발행일처럼 대입할 수 있으므로, 엄격한 발행일 보장을 위해 기사 페이지의 `datePublished` 확인 단계를 추가해야 한다.
